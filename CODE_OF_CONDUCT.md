# Code of conduct

Be kind and assume good intent. People here are fixing their own headphones in their free time, and many of them write in a second language.

No harassment, insults or personal attacks, in issues, pull requests or anywhere else connected to the project. Disagree about code as much as you like, but keep it about the code.

If someone makes you uncomfortable, write to me through the contact on [my GitHub profile](https://github.com/saiv0n) and I'll deal with it. Comments, issues or contributors that don't follow this may be removed or blocked.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
